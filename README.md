# LACHI — Shop Your Style

LACHI is an elegant e-commerce shopping website featuring fashion, jewellery, beauty, and accessories.

## Features
- Browse products with images and prices
- Search and filter products by category
- Sort products by price and name
- Add products to the shopping cart
- Update quantities and calculate totals
- Demo checkout system

## Technologies Used
- HTML
- CSS
- JavaScript
- Python Flask
- Flask-CORS

## Project Structure
- `index.html` — Frontend website
- `app.py` — Flask backend API
- `requirements.txt` — Python dependencies

## How to Run

1. Install Python.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Start the backend from the backend folder:

   `python app.py`

4. Open `frontend/index.html` in your browser.

## Note
This project is a demo. Real payment processing and order management are not connected yet.
